# Trabalho neste repositório

- Converse e mantenha a documentação de produto em português.
- Comece pelo README e leia apenas o documento necessário para a tarefa.
- Este repositório está na fase de concepção. Uma tarefa de documentação não autoriza iniciar implementação, instalar dependências ou alterar o Home Assistant.
- Preserve a diferença entre MVP da mesa, visão de futuro e maturidade para divulgação ativa.
- Não apresente propostas, escolhas de stack ou metas de desempenho sem medição como decisões já firmadas.
- Ao mudar escopo ou decisões, atualize os documentos afetados e mantenha os links coerentes.
- Não adicionar credenciais, configurações privadas completas ou inventários da instalação pessoal.
- As convenções gerais da devbox continuam na entrada local de contexto; este arquivo contém apenas regras do projeto.
