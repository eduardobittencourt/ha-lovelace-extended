# Security policy

## Project and support status

Lovelace Extended is in conception and currently contains documentation and
OpenSpec process files. There is no implemented card, installable package or
published release, and no supported product-version matrix or security update
window has been established.

Security concerns about the repository's existing material can still be
reported privately. Do not include vulnerability details in public issues,
pull requests or ordinary contribution discussions.

## Report privately

Use [GitHub private vulnerability reporting](https://github.com/eduardobittencourt/ha-lovelace-extended/security/advisories/new).
You can also open the repository's **Security** tab and choose **Report a
vulnerability**. Sign in to GitHub to submit a private report to the repository
maintainer. Repository administrators may instead see the draft advisory flow.
Private vulnerability reporting is enabled for this repository.

Include a clear description, affected file or revision, potential impact and
safe reproduction steps when available. Redact credentials and unrelated
personal or installation details. Do not test against someone else's Home
Assistant installation or publish sensitive proof-of-concept data.

The maintainer will assess reports and coordinate any remediation and disclosure
through the private advisory. No response deadline, fix deadline or release
support period is promised at this stage.

For ordinary documentation questions and proposals, follow
[CONTRIBUTING.md](CONTRIBUTING.md). For conduct violations, use the private
contact in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md); the security advisory channel
serves vulnerability reports.
